# Lattice Forge changelog

One line per main change. Newest first.

## 0.9.12 (2026-10-08)
- Shorter, plainer text throughout the app; the details moved to Help.
- Press F1 while pointing at any control or menu to open its Help page.
- A one-time tip about F1 after a new account is set up.

## 0.9.11 (2026-10-07)
- Your own system prompt: one for every session, plus one per project that can replace it.
- The online installer: one small program that installs the newest version with your enrollment code.

## 0.9.10 (2026-10-06)
- The app can shorten long conversations itself (summarize, then leave out the oldest messages).
- Choose which model writes those summaries (Server ▸ Summarizer model).
- Leaving Raw mode asks whether its messages are kept.
- Updates always pick the right file, and the update zip works everywhere.
- American spelling throughout.

## 0.9.9 (2026-10-04)
- A redrawn connection indicator on each session's top row, sharp at any display scaling.

## 0.9.8 (2026-10-04)
- The app proves it is still connected during long replies; a dropped connection is explained, with Retry.
- A status indicator shows the connection check, the reply, the confirmation and the model writing.

## 0.9.7 (2026-10-02)
- Renamed to Lattice Forge, with a new icon.
- A setup program comes with every release.
- Settings move to their own Lattice Forge folder.

## 0.9.6 (2026-10-01)
- Built-in Help: pages by topic, search and links, plus a Getting started PDF.
- Plainer menu names and wording throughout.
- Setting up is offered when the app starts with no server.
- Set up a second computer with a code made on your first one.

## 0.9.5 (2026-10-01)
- Better file tools for the model: read part of a file, and search.
- A turn too large for the server is explained instead of retried.
- The app tries the server's other addresses when one fails.
- Settings show one row per setting; reasoning can be None or Auto.

## 0.9.4 (2026-09-24)
- Each computer gets its own sign-in.
- Error reports and Send feedback.
- Stop also cancels the work on the server.
- Rehydrate, End session and standing rules kept as documents next to the app.
- Sign in from the terminal.

## 0.9.3 (2026-09-21)
- Security fixes for updates, saved sign-ins, file tools and the control link.
- Setting up a computer moved to the desktop app only.

## 0.9.2 (2026-09-20)
- Optional updates: a banner offers the new version without blocking.
- Help ▸ About shows the version, build and server.
- Each tab names its server.
- Install an update from a file, without a network connection.

## 0.9.1 (2026-09-20)
- The app can update itself.

## 0.9.0 (2026-09-14)
- First release: the desktop app and terminal client, setting up a computer with an enrollment code, Raw context mode, and the shared-priority bar.
